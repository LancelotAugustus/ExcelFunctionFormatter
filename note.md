### 4. Git Trailer Convention

[https://git-scm.com/docs/git-interpret-trailers](https://git-scm.com/docs/git-interpret-trailers)

- **类型**：
    - `feat`: 新功能
    - `fix`: 修复 bug
    - `docs`: 文档变更
    - `style`: 代码格式（不影响代码含义）
    - `refactor`: 重构
    - `perf`: 性能优化
    - `test`: 增加测试
    - `chore`: 构建过程或辅助工具变动
    - `revert`: 回退

- **作用域**：
    - `cache`: 缓存
    - `data`: 数据
    - `excode`: 探索性代码
    - `note`: 手册
